# Changelog

## 0.2.0 — 2026-10-10

- Redesigned Signal workspace with light and dark themes, responsive layouts, project artwork and reduced-motion support.
- Grid/list views, sorting, saved projects, keyboard command menu, focus mode, editable tasks and project steps, inbox actions and undo.
- Capsule explorer with searchable recorded responses, replay coverage, safe response previews and blocked-action filters.
- Downloadable session diagnostics without response bodies, compact controls and restart confirmation.
- Expanded offline interaction, keyboard, accessibility and 320–1440 px layout checks.

## 0.1.0 — 2026-10-09

First public release.

- Source-owned Vite apps exported as one portable HTML file.
- Read-only JSON/text API recording, deterministic request matching and configurable field redaction.
- Fetch and async XHR replay with visible misses and restrictive resource policy.
- Scripted offline journeys, startup-only checks, JSON reports bound to the HTML by SHA-256.
- CLI commands for initialization, capture, verification and inspection; typed JavaScript API.
- Signal, Objects and Fieldbook examples covering React, XHR and hash routing.
- Browser tests, mobile layout checks, accessibility checks, and cross-platform CI.

See [compatibility](docs/compatibility.md) for the intentionally limited first-release contract.
